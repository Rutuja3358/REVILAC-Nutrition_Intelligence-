# Release note — patient-controlled source explorer

- Added a nutrient source explorer for protein, fibre, iron, calcium, vitamins, selected minerals, energy, carbohydrate, unsaturated fats, and hydration.
- Shows plain-language roles and broad food-source groups.
- Patient chooses what to consider and can record their own food/source and amount; the UI does not prescribe a recipe.
- Stores choices locally on this browser/device only.
- This is an educational source explorer. It does not claim to calculate nutrients for a saved choice; use the Nutrition Calculator and enter verified values from a trusted source.
- Clinical validation and authoritative food composition integration remain outstanding.
