# REVILAC v3.13 — Cross-device account/sync prototype

## Added
- Account & sync UI with prototype registration and login.
- Node built-in HTTP API for account registration, login, logout, session check and explicit data upload/download.
- Scrypt password hashing, random bearer tokens, hashed session tokens, 8-hour expiry, request body limits, no-store API responses and local server data file.
- `START_ACCOUNT_SERVER.cmd` and package tests.

## Boundaries
This is a development prototype for synthetic/demo data only. No email/SMS OTP, account recovery, MFA, managed cloud database, HTTPS hosting, robust abuse controls, formal privacy compliance, or independent security audit is included. Do not use real health information or expose the server to the internet.
