# REVILAC v3.26 — Nutrition Calculator Integration

- Added a separate Nutrition Calculator modal to the existing index.html without replacing prior modules.
- Supports user-entered per-100-g data for energy, macros, fibre, sodium, potassium, calcium, iron, magnesium, zinc, vitamins C/D/B12 and folate.
- Calculates selected-portion values, sums daily entries, reports per-nutrient data coverage, allows removal/swap workflow, and exports CSV.
- Does not bundle invented food values or automatically create clinical targets.
- See NUTRITION_CALCULATOR_v3.26.md for limitations and instructions.
