# REVILAC Nutrition Intelligence — one consolidated package

This ZIP includes source, static PWA output, tests, and the audit report.

## Local demo
- Requires Node.js >=20.
- Install dependencies only if running server-side functionality: `npm install`
- Run automated tests: `npm test`
- Run syntax checks: `npm run test:syntax`
- Rebuild static PWA: `npm run build:pages`
- Follow `FREE_SETUP_AND_DEPLOYMENT_GUIDE.md` and `DEPLOYMENT_AND_CROSS_DEVICE_GUIDE.md` for deployment details.

## Report ranking
The report-family match percentage ranks keyword-match relevance, not clinical severity or probability. Review the original report and values. Unknown report types must be reviewed manually. This is not universal coverage of every report worldwide.

## Safety
This is a development/demo build, not certified production clinical software. Do not use identifiable patient data or use its output as a diagnosis/treatment decision. Clinical validation, security/privacy review, and browser/device end-to-end validation remain required.
