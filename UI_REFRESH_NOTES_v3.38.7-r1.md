# REVILAC Nutrition Intelligence v3.38.7-r1 — Responsive UI Refresh

This package is based on the supplied v3.38.7 Login_First ZIP. It preserves existing application logic and adds a restrained navy/teal/white responsive visual layer with subtle depth, focus states, mobile sizing, and reduced-motion support.

## Important status
- This is a UI refresh of the existing package, not a claim that every feature is production-ready.
- Existing tests and reported release blockers remain applicable.
- No real patient data should be used for demo; use synthetic/de-identified reports.
- Static PWA hosting does not provide cross-device data sync or a secure patient-sharing backend.
- Browser and real-device testing must be completed on the target devices.

See `START_HERE_ZERO_COST_v3.38.7.md` and `ZERO_COST_PUBLIC_LAUNCH_GUIDE_v3.38.7.md` for the existing run/deployment path.
